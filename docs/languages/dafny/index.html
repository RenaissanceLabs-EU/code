Proof language · 2008

Dafny

Dafny is a programming language with verification built in. Next to ordinary code you write what each method requires and guarantees, and a static verifier tries to prove, automatically and while you type, that the code meets those promises. It aims to make proving a program correct feel like getting it to compile.

How it runs

The Dafny verifier translates the program and its specifications to the Boogie intermediate language and asks the Z3 solver to prove them; verified code is then compiled to C#, Java, JavaScript, Go or Python.

Types: static. Style: imperative, functional, specifications (pre- and postconditions, invariants).

Euclid's algorithm in Dafny

Dafny
function Gcd(a: nat, b: nat): nat
  decreases b
{
  if b == 0 then a else Gcd(b, a % b)
}

lemma GcdZero(a: nat)
  ensures Gcd(a, 0) == a
{}

method Main() { print Gcd(48, 18), "\n"; }

Not run here. Not run: no Dafny toolchain on this Mac. Expected output: 6. The decreases clause lets the verifier prove termination, and the small lemma is proved automatically by unfolding the definition once.

What it is used for

  • verified algorithms and data structures
  • verified cryptographic and security libraries
  • verified distributed systems
  • teaching program verification

Built with it

  • IronFleet Microsoft Research's Ironclad project used Dafny to verify the safety and liveness of practical distributed systems. source
  • AWS Encryption SDK for Dafny Amazon publishes an implementation of its client-side encryption library, the AWS Encryption SDK, in Dafny. source
