44 languages, placed on the stack

Every general-purpose language can compute the same things. They differ in where they sit between the machine and the person, and in what they refuse to let you get wrong. This map places each language at the level of the stack where it does its characteristic work, and shows how much open material exists for training a model to write it.

Twelve families

Languages cluster by what they are for. The families below are a practical grouping, not a strict taxonomy, and many languages borrow from several.

Hardware description

Languages that describe circuits. The text is not a list of steps: it describes wires and gates that all act at once.

VerilogVHDL

Machine level

The processor's own instructions, or a thin readable layer over them.

Assembly languageWebAssembly

Systems

Languages that compile straight to machine code and leave memory in the programmer's hands. Operating systems, browsers and databases are written in them.

CAdaC++GoRustZig

Application

Compiled languages for building large applications, usually on a runtime that looks after memory. The workhorses of business software and mobile apps.

COBOLJavaC#ScalaKotlinSwift

Scripting

Dynamically typed languages made for writing programs quickly. They trade machine speed for programmer speed, and they glue most systems together.

PerlPythonLuaJavaScriptRubyPHPTypeScript

Functional

Languages built around functions and values that do not change. Ideas now found everywhere, such as garbage collection and type inference, started here.

LispErlangHaskellOCamlElixir

Numeric and scientific

Languages built for mathematics on arrays of numbers: science, statistics, engineering and simulation.

FortranMATLABRJulia

Query and logic

Languages in which you state what is true or what you want, and the system searches for the answer.

PrologSQL

Shell

Languages for commanding an operating system: starting programs and connecting them to each other.

BashPowerShell

Markup and configuration

Languages that describe a document or a desired state instead of a computation.

HTML and CSSHCL (Terraform)

Proof

Languages in which a program can carry a machine-checked proof that it is correct, and in which mathematics itself can be written.

IsabelleRocq (Coq)TLA+DafnyLean

Smart contract

Languages for programs that run on a blockchain, where code is public, every step has a price, and a deployed program cannot be patched.

Solidity

Seventy years, in order

Languages are not replaced so much as layered. Fortran, Lisp and COBOL, all from the 1950s, are still in use.

Where the training data is

The count for each language is the number of datasets, benchmarks and environments in the catalog whose own documentation lists that language. It measures what is openly available to train and test on, not how good or how popular a language is. Every language here appears in at least one large corpus of public code, but that is where it ends for many: only 32 of the 44 have a benchmark that covers them, and only 21 have an environment a model can practice in.
