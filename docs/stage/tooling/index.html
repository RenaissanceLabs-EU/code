Stage 06

Tools: data pipelines, sandboxes, trainers

Dedup, decontamination, sandboxes, and the frameworks that run the training.

Who needs this

The supporting cast. Pick tools by what you already run: a single GPU box, an HPC cluster with Apptainer, or a managed cloud.

Decisions you will make

  • Data tooling: how you deduplicate, decontaminate, filter licenses, and remove personal data.
  • Sandbox: Docker with strict flags on one machine, rootless containers on a cluster, or a hosted sandbox service.
  • Trainer: a simple SFT trainer first, an RL framework only when you are ready for rollouts.

Pitfalls

  • Running model-generated code on your host. Always use a container or VM with no network and limited memory, CPU, and processes.
  • Rolling your own dedup or decontamination without testing it on known duplicates.
  • Choosing an RL framework before you have a verifier. The verifier is the hard part.
