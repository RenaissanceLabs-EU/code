Why code can be trained on at all

A model learns from feedback, and code is unusual in how much feedback a machine can give without a person. Each form of a program is a check: it parses or it does not, the types agree or they do not, the tests pass or fail, the proof is accepted or rejected. Training a coding model is the craft of turning those checks into data and rewards without fooling yourself.
