Training datasets, evaluation benchmarks and interactive environments for code, with what each contains, what it supports, its format, size and limits, and the evidence that it is used.

51 resources chosen as a starting point, not a census: 33 training datasets, 12 evaluation benchmarks and 6 interactive environments. Each row says what a record holds, what it can teach, the languages it covers, how it is stored, its size and its limits, with links to the original source and the Hugging Face page. Evidence of use is a number and a date from the Hugging Face or GitHub API, plus the open models in our recipe comparison whose reports say they used it. We do not call anything popular without one of those. Maturity tags: Established widely used for years, Emerging in recent open recipes, Experimental new with little independent use.

Datasets, benchmarks and environments are different thingsA training dataset is data you fit a model on. An evaluation benchmark is a held-out test you measure with, and should stay out of training. An interactive environment is a task with a runnable verifier, used for evaluation and for reinforcement learning. The same repository can appear as more than one, so check which role you are using it in.
