CloudEval-YAML

Benchmark for generating cloud-native configuration in YAML for Kubernetes, Envoy and Istio, with original, simplified and translated versions of each problem.

How to use it

Run the benchmark script against your model. The README shows per-problem output and a summary table.

Caveats

Last commit 2026-09-10. Languages is set to multi because the catalog has no id for YAML.
