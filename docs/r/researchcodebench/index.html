ResearchCodeBench

Tests whether a model can implement the core contribution of recent machine learning papers (2024 to 2025) as code that passes unit tests, given the paper and the surrounding repository.

How to use it

Run the sanity check first to confirm each codebase's tests pass in your environment, then evaluate.

Caveats

No license file in the repository. The paper abstract reports the best model at 37.3% at release. Last commit 2025-06-04. The papers are from 2024 to 2025, so newer models may have seen them.
