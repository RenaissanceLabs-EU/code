Dataset · 2023-08

ComPile

LLVM intermediate representation compiled from permissively licensed production code in C, C++, Rust, Swift and Julia. The largest open IR corpus this pass found.

How to use it

Stream it and disassemble bitcode to textual IR for pretraining models that read or optimize IR. Keep the license columns with each module.

Caveats

Very large; do not download whole. Last modified 2024-04-03.
