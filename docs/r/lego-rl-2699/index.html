Lego-RL-2699 and LegoFlow-SWE

SWE-Lego family: Harbor-format RL environments, teacher trajectories and a Harbor-packaged SWE-bench Verified for evaluating against the same trainer.

How to use it

Use if your trainer reads Harbor tasks; check AGPL implications before redistributing derived data.

Caveats

AGPL-3.0 on RL set is restrictive. LEGO-RL paper id seen in card (2608.17393) not independently opened. SWE-Lego code repo Apache-2.0.
