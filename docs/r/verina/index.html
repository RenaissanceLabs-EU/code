Verina

Verifiable code generation in Lean: each task has description, Lean code, signature, tests and rejected inputs; evaluates code, spec and proof generation. VerinaLite/Plus variants exist.

How to use it

Good for training models to write code plus specs plus proofs, with Lean checker as verifier.

Caveats

Tiny (189 tasks). Treat as eval or few-shot.

load
from datasets import load_dataset
ds = load_dataset("sunblaze-ucb/verina", split="train")
