R2E-Gym (Subset)

Procedurally generated executable environments from commits (back-translated issue text, LM-generated tests) used to train SWE agents and verifiers; includes dev splits in the Lite variant.

How to use it

Use as a second RL source beside real-issue sets; pull images named in docker_image.

Caveats

Problem statements are back-translated, tests partly LM-written, so label noise exists. Code repo last pushed 2025-07-13. The Lite variant card has no license field.
