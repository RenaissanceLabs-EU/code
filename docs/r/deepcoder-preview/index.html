Dataset · 2025-04

DeepCoder-Preview-Dataset

Verified-test competitive programming set used to train DeepCoder-14B: TACO verified, PrimeIntellect SYNTHETIC-1 code and LiveCodeBench problems with test lists.

How to use it

Standard small RL pool for GRPO code runs; run tests with a sandbox (SandboxFusion, verl's code reward).

Caveats

Includes LiveCodeBench v5 train problems, so do not eval on lcbv5 train/test overlap. Only 2 of the configs inspected; 24K figure from card.

load
from datasets import load_dataset
ds = load_dataset("agentica-org/DeepCoder-Preview-Dataset", "lcbv5", split="train")
