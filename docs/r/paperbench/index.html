PaperBench

Agents replicate ML papers from scratch; rubric-graded by an LLM judge. Also ported to inspect_evals (paperbench).

How to use it

Niche research-agent eval; very expensive.

Caveats

Not execution-only: scoring uses an LLM judge with author-co-developed rubrics. License of the official data not verified here.
