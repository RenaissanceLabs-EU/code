Benchmark · 2024-10

MLE-bench

Agents train models, prepare data and run experiments on real Kaggle competitions, graded against human leaderboards.

How to use it

Only relevant for ML-engineering agents; very expensive (GPU hours per task).

Caveats

Execution and leaderboard-based. Paper abstract: o1-preview with AIDE reached at least bronze in 16.9% of competitions (2024). Needs Kaggle data downloads and GPUs.
