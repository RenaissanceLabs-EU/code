CVDP (Comprehensive Verilog Design Problems)

NVIDIA benchmark for RTL design and verification, with both single-turn and agentic problems written by hardware engineers. Covers RTL generation, verification, debugging, specification alignment and technical Q&A.

How to use it

Pick a config (nonagentic, agentic, or agentic heavy code generation). Each exists in a commercial and a no_commercial variant; read the card to see which one your tool setup can run.

Caveats

The paper abstract reports no more than 34% pass@1 on code generation for the best models at release. The license is not a single SPDX license; read LICENSE and NOTICE before training on it. Row counts on HF (68, 92, 25, 75, 187, 302) do not sum to the 783 in the paper.
