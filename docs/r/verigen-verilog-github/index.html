Verilog_GitHub (VeriGen training data)

Verilog modules collected from GitHub through BigQuery, used to fine-tune the VeriGen models. One of the few sizable open Verilog corpora.

How to use it

Use as raw Verilog for continued pretraining or fine-tuning. Filter by license and compile each module with a simulator or linter before use.

Caveats

The card states the entries can be non-compilable, low-quality and vulnerable code, and that the source was not filtered for permissive licenses. The license statements on the card conflict. Last modified 2023-09-20.
