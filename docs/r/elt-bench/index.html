ELT-Bench

End-to-end benchmark on building ELT (extract, load, transform) data pipelines with agents, graded on the data models the pipeline produces.

How to use it

Follow REPRODUCE.md. You need a data warehouse account (the evaluation supports Snowflake, Databricks and Redshift naming) and the Docker setup in the repository.

Caveats

The paper abstract reports 3.9% of data models correct for the best agent at release, at an average of $4.30 per pipeline. The default branch is now an extended version called ELT-Bench++. Needs a data warehouse account. Last commit 2026-11-17.
