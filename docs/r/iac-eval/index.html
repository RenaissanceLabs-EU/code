Benchmark · 2024-06

IaC-Eval

Infrastructure-as-code generation benchmark from NeurIPS 2024: write Terraform programs for AWS from a natural-language request, graded against policy checks.

How to use it

Install Terraform and Open Policy Agent as the README describes, generate a Terraform program per question, and run the framework's checks.

Caveats

AWS only for now, per the README. Setup needs AWS credentials. GitHub last commit 2024-12-12.
