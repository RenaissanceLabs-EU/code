CRUST-Bench

C to safe Rust transpilation at repository scale. Each C repository is paired with a hand-written safe Rust interface and tests that the translation must pass.

How to use it

Translate each repository to Rust that matches the given interface, then build and run the Rust tests. Report single-shot and repair-loop results separately.

Caveats

The paper abstract reports the best model solving 15 of 100 tasks single-shot at release. GPL-3.0 applies to the dataset. Last commit 2026-04-27.
