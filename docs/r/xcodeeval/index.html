Benchmark · 2023-03

xCodeEval

Executable multilingual benchmark with seven tasks, including program synthesis, repair, code translation and retrieval, scored by unit tests through the ExecEval engine.

How to use it

Use the code translation and program repair tasks with ExecEval for test-based scoring across languages.

Caveats

The card says up to 17 languages while the current paper abstract says 11. Large; load one task at a time. Problems come from a public competitive programming site, so contamination is likely. The viewer returned an error when checked.
