KernelBench

Stanford benchmark on writing fast and correct GPU kernels: translate PyTorch operators and models into CUDA (or other DSL) code that matches the reference output and runs faster. From ICML 2025.

How to use it

Score both correctness and speedup over the PyTorch baseline on a fixed GPU. The speedup gives a continuous reward, which suits RL.

Caveats

The kernels here are GPU compute kernels, not operating system kernels. Timing depends on the GPU, so results are not comparable across hardware. The paper abstract reports models beating the PyTorch baseline in under 20% of cases at release. Last commit 2026-03-05.
