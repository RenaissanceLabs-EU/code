Llama-Nemotron-Post-Training-Dataset (code)

Post-training data for Llama-3.3-Nemotron-70B and Llama-3.1-Nemotron-Ultra-253B; v1.1 added 500K code reasoning samples.

How to use it

Use the SFT/code split with its reasoning on/off labels; subsample heavily.

Caveats

Teachers include DeepSeek-R1, Qwen-2.5-Coder-32B-Instruct, Qwen-2.5-72B, Llama-3.3-70B and Mixtral-8x22B per the card; parts are subject to Llama license redistribution terms. Very large.
