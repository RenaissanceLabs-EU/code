ITBench

IBM-led benchmark of IT automation tasks for agents in three areas: site reliability engineering, compliance and security operations (CISO), and cloud cost management (FinOps).

How to use it

Self-host the scenarios with the repository tooling, or use the hosted scenario environments and leaderboard described in the README.

Caveats

The paper abstract reports agents resolving 13.8% of SRE, 25.2% of CISO and 0% of FinOps scenarios at release. The README notes that ITBench-AA, launched 2026-05-27 with Artificial Analysis, starts with 59 SRE tasks. Actively maintained (last commit 2026-11-24).
