Dataset · 2020-11

WasmBench

Real-world WebAssembly binaries collected from websites, GitHub, NPM and browser extensions, from the WWW 2021 study of WebAssembly in the wild.

How to use it

Download the filtered release archive. Convert to the text format with standard tools if you want token-level training data or decompilation inputs.

Caveats

Binaries only, with no paired source and no tasks. The authors do not claim ownership of the binaries, so licensing per file is unknown. Last commit 2022-07-20. This pass found no open LLM benchmark specific to WebAssembly.
