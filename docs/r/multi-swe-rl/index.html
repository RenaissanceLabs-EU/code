Multi-SWE-RL

ByteDance Seed community effort to collect multilingual SWE RL instances (unannotated new instances plus discarded Multi-SWE-bench instances).

How to use it

Treat as raw material: you must build environments with the multi-swe-bench toolkit before using it for RL.

Caveats

Unannotated and license is vague ('other'). Last HF update 2025-07-23. Little documentation of sizes in the card, so size is not verified.

LicenseThis entry is not plainly permissive (family: unknown, read the source). Read the license on the source page before using it for training or for a product.
