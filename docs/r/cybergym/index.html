CyberGym

Evaluation of agents on real-world vulnerability analysis. Each task gives the vulnerable repository and, at higher difficulty levels, more hints such as a description, an error trace or the fixed code.

How to use it

For evaluation and defensive research. Download the server data and run agents in the provided containers.

Caveats

Heavy: the README gives about 240 GB for the full data and about 130 GB for binary-only mode. The paper abstract reports about 20% success for the best setups at release. Languages were set from the project_language field of sampled rows, not a full count. Dual-use content; keep runs sandboxed. Last commit 2026-08-28.
