OpenCodeInstruct (NVIDIA)

Largest open code instruction set: each row has question, solution, generated unit tests, execution results and an LLM quality assessment, so you can filter by test score.

How to use it

Filter on average_test_score and llm_judgement before SFT; do not train on all 5M blindly. Stream it, it is ~19 GB uncompressed.

Caveats

Per the paper, solutions, tests and judgments came from Qwen2.5-Coder-32B-Instruct (Qwen license terms apply to outputs). Tests are model-written, so a passing row is not guaranteed correct. Python-centric.

load
from datasets import load_dataset
ds = load_dataset('nvidia/OpenCodeInstruct', split='train', streaming=True)
# columns: id, input, output, domain, generation_algorithm, llm_judgement, unit_tests, tests_execution_status, average_test_score
