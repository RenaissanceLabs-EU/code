ML-Bench

Tests whether a model can use existing machine learning repositories: read the documentation and code, then produce the right script or command with the right arguments.

How to use it

Use the quarter split for a quick check and full for reporting. The train splits allow fine-tuning for in-distribution and out-of-distribution comparison.

Caveats

Tied to 18 specific repositories at fixed versions. GitHub last commit 2025-07-31.

load
from datasets import load_dataset
ds = load_dataset("super-dainiu/ml-bench", split="quarter")
