Dataset · 2024-02

CodeFeedback-Filtered-Instruction

287K queries from Magicoder-OSS, Python ShareGPT, Magicoder-Evol and Evol-Instruct, filtered to complexity 4-5 by Qwen-72B-Chat.

How to use it

Use when you want a complexity-filtered union of earlier instruction sets instead of the raw parents.

Caveats

Card warns that part of the data was generated by OpenAI models. Overlaps heavily with Magicoder data. Filter used a model-assigned complexity score, not execution.
