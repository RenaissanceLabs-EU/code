CORE-Bench

Computational reproducibility benchmark from Princeton: given the code and data of a published paper in computer science, social science or medicine (Python or R), run it and answer questions about the results.

How to use it

Run through the Holistic Agent Leaderboard harness, which the README now recommends. Task files hold prompts and questions; the harness downloads each paper's code capsule.

Caveats

The original harness is no longer actively maintained (README); last commit 2025-11-23. The paper abstract reports 21% on the hardest level for the best agent at release.
