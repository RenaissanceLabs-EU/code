Dataset · 2025-05

rStar-Coder

Competitive problems with mutually verified test cases, with configs synthetic_sft, synthetic_rl, synthetic_rl_testcase, seed_sft, seed_testcase.

How to use it

Use synthetic_rl plus synthetic_rl_testcase for RL; seed_* configs have real problems.

Caveats

Test cases live in separate config, join by id. Large. Solutions from Qwen/DeepSeek models.
