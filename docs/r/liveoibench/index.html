LiveOIBench

Olympiad-level competitive programming benchmark using official test cases and offline judging, with human-contestant percentile comparison.

How to use it

Candidate hard gate when you want olympiad difficulty with official tests and no online-judge dependency.

Caveats

Execution-based. Per a search result summary of the paper, GPT-5 reached about the 82nd percentile versus top human contestants usually above the 90th (not independently verified in this pass). I did not verify a data link or license, so only the paper is linked.
