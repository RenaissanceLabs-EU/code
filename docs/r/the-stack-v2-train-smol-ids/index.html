The Stack v2 train (smol ids)

Id list for the smaller training subset of The Stack v2 used in StarCoder2 training; a lightweight route to a few-hundred-billion-token mix.

How to use it

Start here if the full v2 is too large; download contents from SWH using the ids.

Caveats

Ids only; contents need Software Heritage S3. Gated. Subset definition not verified from the card (could not read).
