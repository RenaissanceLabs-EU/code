Dataset · 2023-01

CommitPack

Raw commit corpus (code before/after plus message) from which CommitPackFT was filtered.

How to use it

Use when you want to build your own commit-based edit data or commit-message models. Most SFT users want CommitPackFT instead.

Caveats

Very large and noisy. Not a download for low-resource machines.
