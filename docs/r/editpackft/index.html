Dataset · 2023-12

EditPackFT

Further-filtered CommitPackFT subset formatted for instructional code editing (before code, instruction, after code), used to train CanItEdit-evaluated models.

How to use it

Use to teach instruction-following code edits; evaluate with CanItEdit.

Caveats

Small. Derived from commit messages, so instruction quality varies.

load
from datasets import load_dataset
ds = load_dataset('nuprl/EditPackFT', split='train')
# columns include: instruction, old_contents, new_contents, lang, commit
