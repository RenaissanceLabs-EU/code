Seed-Coder-8B (Base/Instruct/Reasoning)

ByteDance Seed (2025) family built from model-curated pretraining data; base, instruct and RL-trained reasoning variants in one permissive license.

How to use it

Use the base for a small MIT-licensed code starting point and the Reasoning model as a small teacher.

Caveats

Data pipeline relies on LLM filtering; training data itself is not released. Mid-2025 vintage.
