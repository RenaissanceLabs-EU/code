InterCode

Framework for interactive coding environments in Docker, where the agent issues commands and sees execution feedback. Ships Bash, SQL and Python environments built from NL2Bash, Spider and MBPP.

How to use it

Use the Bash environment for multi-turn shell tasks with real execution. The gym-style interface also makes it a template for your own environments.

Caveats

Task data comes from older public datasets, so contamination is likely. Last commit 2024-05-05.
