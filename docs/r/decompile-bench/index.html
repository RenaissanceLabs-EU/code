Dataset · 2025-05

Decompile-Bench

Function-level pairs of compiled binary (as assembly) and original C or C++ source, condensed from 100 million pairs compiled from permissively licensed GitHub projects. Training data for the LLM4Decompile models.

How to use it

Fine-tune a model to map assembly or decompiler pseudo-code back to source. Evaluate on Decompile-Bench-Eval, which uses later repositories.

Caveats

The card says 450 GB of binaries were compiled to build it. The row count shown by the viewer is lower than the two million in the card; check before relying on either number.
