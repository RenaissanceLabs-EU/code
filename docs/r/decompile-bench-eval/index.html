Decompile-Bench-Eval

Evaluation set for binary decompilation: hand-built binaries from HumanEval and MBPP, plus GitHub repositories released after 2025 to limit leakage. C and C++.

How to use it

Decompile each function and score with the scripts in the LLM4Decompile repository.

Caveats

The HumanEval and MBPP parts inherit the contamination of those benchmarks. LLM4Decompile repository last commit 2026-02-12.
