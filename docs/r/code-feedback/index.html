Code-Feedback (OpenCodeInterpreter)

Multi-turn code data with execution feedback and human-feedback-style follow-ups for iterative refinement (OpenCodeInterpreter).

How to use it

Include if you want a model that reads execution output and fixes its code over several turns.

Caveats

Card says part of it was generated by GPT-4-0613 and GPT-3.5-turbo-0613 (OpenAI usage policy applies). The headline 91.6 HumanEval/MBPP average in the paper used synthesized GPT-4 feedback at inference.
