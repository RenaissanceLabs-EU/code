Dataset · 2024-07

SmolLM-Corpus (Python-Edu, Cosmopedia, FineWeb-Edu-Dedup)

Pretraining corpus of SmolLM v1 including Python-Edu: Python files scored 4 or more by an educational code classifier.

How to use it

Use python-edu as a compact high-quality Python source; Cosmopedia adds synthetic textbook text.

Caveats

Python only for code; Cosmopedia is synthetic from Mixtral, with that model's terms. Superseded for code by Stack-Edu. Python-edu includes file text; license inherited from source repos.

load
from datasets import load_dataset
ds = load_dataset("HuggingFaceTB/smollm-corpus", "python-edu", split="train", streaming=True)
