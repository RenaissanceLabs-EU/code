SWE-rebench (nebius, v1)

Continuously mined Python GitHub issue tasks with install configs, F2P/P2P tests and docker_image names, from Nebius; also feeds a decontaminated leaderboard.

How to use it

Use the filtered split for quality; docker_image/install_config let you reproduce environments. Good RL pool next to SWE-Gym and R2E-Gym.

Caveats

The huge test split is unfiltered: some tasks have ambiguous statements or weak tests. Underlying repo licenses vary (license_name column). Check time overlap with your eval set.

load
from datasets import load_dataset
ds = load_dataset("nebius/SWE-rebench", split="filtered")
