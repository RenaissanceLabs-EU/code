Dataset · 2022-03

ManyTypes4TypeScript

TypeScript type prediction dataset: token sequences with a type label per token, taken from human annotations and compiler-inferred types.

How to use it

Use as a token-classification or sequence-to-sequence task for type inference. Splits are by project, which limits leakage between train and test.

Caveats

Last modified 2022-10-22. Data is pre-tokenized, which fits encoder models better than chat models. Many labels are compiler-inferred and not written by people.

load
from datasets import load_dataset
ds = load_dataset("kevinjesse/ManyTypes4TypeScript", split="test")
