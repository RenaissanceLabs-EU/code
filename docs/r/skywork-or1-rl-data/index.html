Dataset · 2025-05

Skywork-OR1-RL-Data

RL-ready math and code problems in verl format (prompt, reward_model.ground_truth) with per-model pass difficulty labels for 1.5B, 7B and 32B R1 distills.

How to use it

Use extra_info.model_difficulty to drop always-solved and never-solved items before GRPO.

Caveats

Card license missing. Code ground truth are large test blobs (about 1.5 GB for 14k code rows).

load
from datasets import load_dataset
ds = load_dataset("Skywork/Skywork-OR1-RL-Data", split="code")
