Benchmark

Aider Polyglot benchmark

Hard Exercism exercises where the model must edit files in aider's format and pass tests, measuring instruction following plus multilingual editing.

How to use it

Use as a cheap-ish multilingual code-editing gate (225 tasks); also tests edit-format discipline. Run with the aider benchmark harness in Docker.

Caveats

Execution-based. Aider's leaderboard (updated 2025-11-20 when I read it) lists gpt-5 (high) at 88.0% in a run dated 2025-08-23, indicating near saturation at the top. Exercism exercises are public and widely seen in training. Small tasks, not repo-scale.
