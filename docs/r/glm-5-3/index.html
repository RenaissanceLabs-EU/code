GLM-5.3

Aug 2026 Z.ai open model; card says it uses the GLM-5.2 base with gains from post-training only, and claims open-source SOTA on Terminal Bench 3.0.

How to use it

Strong open teacher for terminal/agentic data under a mostly permissive license.

Caveats

Card tables are vendor-run and include proprietary baselines; not independently verified. Large MoE.
