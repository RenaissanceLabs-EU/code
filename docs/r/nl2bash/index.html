Dataset · 2018-02

NL2Bash

Bash one-liners collected from sites such as Stack Overflow, paired with English descriptions written by Bash programmers. The classic natural language to shell corpus.

How to use it

Use as seed data for shell command generation. For evaluation prefer an execution-checked derivative such as InterCode or NL2SH-ALFA.

Caveats

From 2018, widely copied, so contamination is near certain. Original scoring is by text match; many commands are not safe to run blindly. Last commit 2026-04-18.
