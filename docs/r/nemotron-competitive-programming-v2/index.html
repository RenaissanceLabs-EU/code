Nemotron-SFT-Competitive-Programming-v2

Competitive coding with reasoning and critique, Python Exercism-style exercises (Aider problems decontaminated), and enterprise text-to-SQL records generated with NVIDIA Data Designer.

How to use it

Pick the subset you need: competitive for reasoning, Exercism for exercise-style, SQL for schema-linking reasoning.

Caveats

Card names DeepSeek-R1-0528 as a generator for the competitive subset; SQL generator not confirmed in the text read. Problem sources have their own licenses.
