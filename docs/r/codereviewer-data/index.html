CodeReviewer dataset

Code review data from Microsoft for three tasks: judge whether a diff needs a review comment, write the review comment, and revise the code to address a comment.

How to use it

Download the archive for the task you need from Zenodo. The model and training code are in the CodeReviewer folder of the microsoft/CodeBERT repository.

Caveats

Published 2022, mined from public pull requests, so contamination is likely and many review comments are noisy. Scoring is by text match. The code repository was last committed to on 2023-07-09.
