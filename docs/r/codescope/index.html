CodeScope

Execution-based multilingual, multitask benchmark covering code understanding and generation across many languages.

How to use it

Rarely used; consider only if you need a broad multilingual multitask sweep and can accept noncommercial terms.

Caveats

Execution-based (per paper). Noncommercial license restricts use in some pipelines. Low adoption and last updated 2023-12, so no maintenance signal.
