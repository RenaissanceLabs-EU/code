Tool · 2015-10

syzkaller

Unsupervised coverage-guided kernel fuzzer from Google. Its crash reproducers are the raw material behind kernel bug datasets such as kBench.

How to use it

Use it to generate fresh kernel crashes and reproducers for a private evaluation set, or to validate that a model-written patch removes a crash.

Caveats

A fuzzer, not a dataset. Running it needs virtual machines and kernel builds. Actively maintained (last commit 2026-11-24).
