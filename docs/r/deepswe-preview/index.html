DeepSWE-Preview

RL-only coding agent trained on Qwen3-32B with 4.5K R2E-Gym problems (sympy-like repos shared with SWE-bench Verified filtered out); card reports SWE-bench Verified rising from 23% to 42% in 200 RL steps.

How to use it

Reference for pure-RL SWE training with rLLM; reuse data filtering idea.

Caveats

Numbers are from the model card (agentica-org). Config context is 40,960 although agent runs use longer contexts via scaffolding. Preview release.
