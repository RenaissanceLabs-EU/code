Model · 2025-07

Qwen3-Coder-480B-A35B-Instruct

July 2025 flagship Qwen coder: large MoE for agentic coding and repository-scale context. Commonly used as a permissively licensed teacher for trajectory distillation.

How to use it

Use as a teacher for synthetic SFT data and trajectories; license permits it. Needs a multi-GPU node.

Caveats

Very large to serve. Superseded in the Qwen line by Qwen3-Coder-Next and Qwen3.8. Check output quality per task before trusting distilled data.
