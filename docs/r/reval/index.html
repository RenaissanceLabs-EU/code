REval

Tests whether a model can reason about the runtime behavior of a program, and whether its answers stay consistent across related questions (incremental consistency). From ICSE 2025.

How to use it

Run the replication package on your model. Report both runtime behavior accuracy and the incremental consistency score.

Caveats

No license file in the repository. Built on HumanEval and ClassEval programs, which are public. The paper abstract reports average accuracy of 44.4% and an average consistency score of 10.3 at release. Last commit 2024-07-03.
