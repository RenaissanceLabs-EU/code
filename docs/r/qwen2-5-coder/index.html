Qwen2.5-Coder family (32B shown)

Sep-Nov 2024 code-specialized Qwen family with base and instruct variants from 0.5B to 32B. Still the most widely used open base for code SFT/RL recipes (SWE-smith, OpenHands LM, Open-R1 style work).

How to use it

Use the base checkpoints (7B/14B/32B) for controlled recipe experiments, since many published results start from them.

Caveats

Old by Nov 2026: newer Qwen3.x models beat it. License verified only for the 32B/7B pages fetched; sizes 0.5B-3B may carry different licenses, check before use. Qwen2.5 bases may be contaminated with reasoning-like data (see Dr. GRPO paper).
