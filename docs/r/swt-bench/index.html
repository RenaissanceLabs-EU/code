SWT-Bench

Agents write reproduction tests for real GitHub issues; a good test fails before and passes after the golden patch.

How to use it

Use to check whether agents can turn issues into fail-to-pass tests, a key skill for RL reward construction.

Caveats

Execution-based. Derived from SWE-bench so shares contamination concerns. HF license not stated.
