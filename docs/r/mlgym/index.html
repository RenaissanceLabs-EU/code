MLGym

Gym environment from Meta for machine learning research tasks in computer vision, language, reinforcement learning and game theory, designed so that agents can also be trained with RL.

How to use it

Run tasks in Docker or Podman containers. The gym interface makes it one of the few ML-research environments shaped for RL training and not only evaluation.

Caveats

The repository is archived; last commit 2025-08-10. Non-commercial license.
