Dataset · 2025-04

SWE-smith trajectories

SWE-agent trajectories with Claude 3.7 Sonnet on SWE-smith instances; columns include messages, resolved, model and patch.

How to use it

Filter on resolved=True before SFT.

Caveats

Generated by Claude 3.7 Sonnet via SWE-agent (card), so Anthropic terms apply to using outputs to train models. Python only.
