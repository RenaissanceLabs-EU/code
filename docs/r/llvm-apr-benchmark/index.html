LLVM APR Benchmark

Program repair on the LLVM compiler itself: each item is a real LLVM issue (for example a miscompilation in InstCombine) with minimal reproducing tests.

How to use it

Give the model the issue and the failing tests and have it patch LLVM. Building LLVM is required, so plan for heavy compute per attempt.

Caveats

Growing dataset, so report the date or revision. Requires an LLVM build environment. The card documents rules on what counts as using hints.

load
from datasets import load_dataset
ds = load_dataset("dtcxzyw/llvm-apr-benchmark", split="test")
