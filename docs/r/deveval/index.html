DevEval (SDLC benchmark, arXiv 2403.08604)

Evaluates LLMs across the software lifecycle: design, environment setup, implementation, acceptance and unit testing. Note the name clashes with other 'DevEval'/'DevBench' projects.

How to use it

Reference only; low adoption. Check which 'DevBench' or 'DevEval' you mean before citing.

Caveats

Part LLM-judged, part test-based. I did not find a verified data release in this pass. Title is a case study, not a mature leaderboard.
