DABstep

Multi-step data analysis tasks from Adyen, drawn from a financial analytics platform. The agent must combine code over data files with reading the accompanying documentation.

How to use it

Develop on the dev split and report on the default split.

Caveats

The paper abstract reports 14.55% accuracy on the hardest tasks for the best agent at release. The dataset repository also stores leaderboard submissions. Actively updated (last modified 2026-11-22).

load
from datasets import load_dataset
ds = load_dataset("adyen/DABstep", "tasks", split="dev")
