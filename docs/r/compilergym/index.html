CompilerGym

Reinforcement learning environments for compiler optimization, exposing LLVM optimization passes as actions with rewards such as reduction in instruction count.

How to use it

Use the llvm environments (for example llvm-ic-v0 with cbench programs) to train or evaluate a policy that orders optimization passes.

Caveats

The repository is archived; last commit 2024-10-09. Built for classic RL agents with a gym interface, not for LLM chat agents, so you need a wrapper.
