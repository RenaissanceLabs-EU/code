Tool

datasketch

Python library for MinHash, LSH, LSH Forest and HyperLogLog used for near-duplicate detection.

How to use it

Building block for custom MinHash-LSH dedup (the method used for Stack v2/v3 near-dedup).

Caveats

Pure Python is slow at web scale; use for prototypes or smaller corpora.
