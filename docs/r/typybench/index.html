TypyBench

Repository-level type inference for untyped Python, from ICML 2025. Introduces TypeSim (semantic similarity of predicted and true types) and TypeCheck (consistency across the codebase).

How to use it

Have the model infer types for each untyped repository, then score with the TypeSim and TypeCheck metrics from the repository.

Caveats

The dataset is a Google Drive download linked from the README, not a versioned release. Last commit 2025-06-22. The released date is the repository creation date.
