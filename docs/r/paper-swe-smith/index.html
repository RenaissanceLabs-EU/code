SWE-smith

Pipeline that turns any Python repo into an execution environment and synthesizes 100s-1000s of task instances by breaking tests; builds a 50k-instance dataset from 128 repos (abstract).

How to use it

Scalable data generator for SWE tasks; start from the released dataset and trajectories.

Caveats

Synthetic bugs differ from real issues; Python only; trajectories used Claude 3.7 Sonnet (terms).
