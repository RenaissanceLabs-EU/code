GitHub Code (CodeParrot)

BigQuery-derived GitHub dump with repo, path, language and license per file; used for CodeParrot.

How to use it

Small-scale experiments; filter by licenses and languages through the loading script options.

Caveats

Includes copyleft code (GPL etc.), not for permissive-only policies without filtering. 2022-era, no dedup, benchmark contamination likely. Uses a loading script (trust_remote_code).
