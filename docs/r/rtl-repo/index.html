RTL-Repo

Repository-level Verilog completion: predict the next line of code given the context of a whole public GitHub RTL project.

How to use it

Evaluate on the test split with the scripts in the GitHub repository. The train split can be used for fine-tuning.

Caveats

The HF card states no license; the GitHub code repository is Apache-2.0. Text-match metrics, no simulation, so it measures completion quality and not functional correctness. Last commit 2024-06-05.
