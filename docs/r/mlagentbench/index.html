MLAgentBench

Machine learning experimentation tasks for agents, from improving a CIFAR-10 model to research problems such as BabyLM. The agent gets a dataset and a task description and must build or improve a model.

How to use it

Run each task in its interactive environment with the repository's runner.

Caveats

Small, and from 2023. Last commit 2024-04-28. MLE-bench (already in the catalog) covers the same ground with more tasks.
