Tool · 2011-05

Csmith

Random generator of C programs free of undefined behavior, built to find compiler bugs by differential testing.

How to use it

Generate programs, compile with two compilers or optimization levels, and compare outputs. Useful as a source of fresh, never-seen C programs for execution-prediction or compiler tasks.

Caveats

A tool, not a dataset. Generated programs are synthetic and unlike human code. Last commit 2026-03-02. The released date is the GitHub repository creation date, not the first publication.
