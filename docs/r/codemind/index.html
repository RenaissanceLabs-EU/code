CodeMind

Framework for code reasoning tasks: predict the output of code on given inputs (Independent Execution Reasoning), use test data in a specification (Specification Reasoning), and infer semantics from one input/output pair (Dynamic Semantics Reasoning).

How to use it

Run the task scripts (for example run_IER.sh) over the supported datasets. Compare execution reasoning scores with test-passing scores for the same model.

Caveats

The README calls it a work in progress. It reuses existing public benchmarks as program sources. Last commit 2026-02-18.
