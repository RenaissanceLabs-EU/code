AceCode-87K (TIGER-Lab)

Questions rewritten by GPT-4o-mini with synthesized test cases; includes completions with pass rates, used for reward models and RL (AceCoder).

How to use it

Build pass-rate preference pairs yourself, or use the ready-made AceCodePair-300K; also usable as RL prompts with tests.

Caveats

Questions and tests rewritten by GPT-4o-mini (OpenAI terms). Test cases are LLM-synthesized and filtered, so imperfect. Completion model names are in a model_name column.

load
from datasets import load_dataset
ds = load_dataset('TIGER-Lab/AceCode-87K', split='train')
# columns: id, source, question, test_cases, inferences
