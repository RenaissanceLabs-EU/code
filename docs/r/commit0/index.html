Benchmark · 2024-12

Commit0

Agent must implement a library from its spec using interactive unit tests; measures long-form spec following.

How to use it

Use as an expensive stress test for from-scratch library generation.

Caveats

Execution-based (unit tests). Small (54 libraries). Repo last pushed 2026-02. Libraries are public so leakage is possible. HF dataset metadata has no license field.
