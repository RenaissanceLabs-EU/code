Dataset · 2025-05

OpenCodeReasoning-2 (NVIDIA)

Second release: R1 generations with QwQ critiques and right/wrong judgements, for both code completion and code critique SFT.

How to use it

Use for reasoning SFT plus critique training; the pass_rate and judgement columns allow filtering.

Caveats

Generations by DeepSeek-R1 and critiques by QwQ-32B (per card fields r1_generation, qwq_critique). Judgement labels are model-produced, not ground truth.
