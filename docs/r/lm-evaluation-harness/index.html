Tool

lm-evaluation-harness (code tasks)

The standard few-shot LLM harness; code coverage is basic.

How to use it

Use for quick HumanEval/MBPP numbers inside a broader multi-task sweep; for serious code evaluation prefer EvalPlus or LiveCodeBench.

Caveats

Code tasks are thin; code execution requires explicit opt-in because it runs untrusted code.
