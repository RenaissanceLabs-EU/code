Spider 2.0

Real enterprise workflows over BigQuery, Snowflake and local databases with 1,000+ columns, requiring metadata search, dialect docs and multi-step SQL.

How to use it

Use as the hard SQL-agent gate; needs cloud DB credentials for the full setting (check repo for local-only variants).

Caveats

Execution-based. Much harder than Spider/BIRD, so not saturated. Some settings require access to commercial cloud warehouses.
