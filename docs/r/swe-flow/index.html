SWE-Flow / Repo2RLEnv swe_flow recipe

Test-driven synthesis: trace passing tests, remove exercised functions, ask the agent to reconstruct them, reward via retained tests. Hugging Face Repo2RLEnv now packages the recipe as Harbor tasks.

How to use it

Use Repo2RLEnv to turn your own repos into Harbor-format RL tasks.

Caveats

Sample HF set is only 100 tasks with mixed source licenses. SWE-Flow repo last pushed 2025-06-29 with 40 stars.
