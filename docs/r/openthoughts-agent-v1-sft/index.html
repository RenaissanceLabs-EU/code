OpenThoughts-Agent-v1-SFT

Teacher-agent traces on nl2bash and InferredBugs (C# and Java bugs) tasks, in the Terminus-2 harness, used for OpenThinker-Agent-v1.

How to use it

Small, terminal-agent oriented SFT set; pair with its RL tasks.

Caveats

Traces generated with GLM-4.6 (AWQ quant) per the card. Only two task families, so narrow.
