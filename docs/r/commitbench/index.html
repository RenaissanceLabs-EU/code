Dataset · 2024-01

CommitBench

Commit message generation data: git diffs paired with their commit messages, from repositories whose licenses permit redistribution. Six languages: Java, Python, Go, JavaScript, PHP and Ruby.

How to use it

Train or evaluate diff-to-message generation. The filtering steps described on the card are also a useful recipe for cleaning your own commit data.

Caveats

Non-commercial license. Scored by text overlap with the human message, which is a weak signal of quality. Last modified 2024-02-14.
