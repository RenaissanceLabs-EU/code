Devstral Small 2 (24B)

Dec 2025 Mistral agentic coding model, Apache licensed; earlier Devstral-Small-2505 and 2507 are also Apache-2.0 (verified).

How to use it

Good Apache-licensed 24B starting point for SWE-agent style SFT/RL.

Caveats

Instruct-only; no base released in what we checked. Card says it performs 'remarkably' on SWE-bench but we copied no number.
