Dataset · 2025-10

Dolma 3 Dolmino mix (100B)

Ai2 OLMo 3 mid-training mix with fill-in-the-middle Stack-Edu, synthetic Python (CraneCode) and code meta-reasoning data.

How to use it

Use as a reference recipe for mid-training proportions (card lists mix percentages) and pull the code configs (stack_edu_fim, cranecode, code_meta_reasoning).

Caveats

Synthetic subsets come from LLMs with their own terms; check card. The mix percentages are Ai2's, not ablated for your model.

load
from datasets import load_dataset
ds = load_dataset("allenai/dolma3_dolmino_mix-100B-1025", "stack_edu_fim", split="train", streaming=True)
