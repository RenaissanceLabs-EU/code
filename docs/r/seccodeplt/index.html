SecCodePLT

Security benchmark built from validated seeds expanded by mutation, with dynamic tests for both code generation and cyberattack helpfulness.

How to use it

Add for secure-code evaluation with dynamic checks.

Caveats

Dynamic test-based. Gated (auto-approval). The paper (listed as SeCodePLT on arXiv) claims better coverage than static-rule benchmarks, which I did not independently check.
