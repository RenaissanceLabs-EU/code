Benchmark · 2024-03

Design2Code

Design-to-code benchmark: given a screenshot of a real webpage, write HTML and CSS that renders to match it.

How to use it

Needs a multimodal model. Render the output and score with the automatic metrics in the GitHub repository.

Caveats

Pages come from the C4 validation set, which is public web data. Scored by visual similarity, not by interaction. GitHub last commit 2024-11-02.

load
from datasets import load_dataset
ds = load_dataset("SALT-NLP/Design2Code-hf", split="train")
