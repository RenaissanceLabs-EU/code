Dataset · 2025-02

open-r1 CodeForces-CoTs

DeepSeek-R1 chain-of-thought solutions in C++ and Python for Codeforces problems, used to train OlympicCoder.

How to use it

Use the decontaminated configs (solutions_decontaminated or solutions_py_decontaminated) for training.

Caveats

Traces generated by DeepSeek-R1. Problems are from Codeforces. Not all traces are verified correct unless using the verified configs; check the card.

load
from datasets import load_dataset
ds = load_dataset('open-r1/codeforces-cots', 'solutions_decontaminated')
