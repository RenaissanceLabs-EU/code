RE-Bench

METR's research engineering benchmark, with human baselines from 71 eight-hour attempts by 61 experts, so that agent scores can be compared with people given the same time.

How to use it

Use for comparison with the published human baselines.

Caveats

The README marks the tasks as deprecated and the repository is archived; METR no longer accepts contributions or bug reports. Last commit 2026-10-20.
