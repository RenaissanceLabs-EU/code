NYU CTF Bench

Dockerized capture-the-flag challenges from the CSAW competitions in six categories: web, binary exploitation, forensics, reverse engineering, cryptography and miscellaneous.

How to use it

For evaluation only. Use the development set to tune the agent and report on the test set.

Caveats

Past competition challenges with public write-ups, so contamination is likely. Dual-use content. Last commit 2025-09-22.
