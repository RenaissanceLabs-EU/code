kGym and kBench (Linux kernel crash resolution)

Platform and dataset for fixing real Linux kernel crashes found by the Syzkaller fuzzer. A patch is judged by building the kernel and re-running the crash reproducer.

How to use it

Use kGymSuite, the successor that runs on QEMU, to build kernels and replay reproducers. Start with the smaller set, which the authors trust more.

Caveats

This repository has no license file; kGymSuite has an MIT license file. The paper abstract reports 0.72% (unassisted) and 5.38% (buggy files given) for the best model at release. Each evaluation is a kernel build, so it is slow and costly. Last commit 2025-11-08; kGymSuite last commit 2026-05-08.
