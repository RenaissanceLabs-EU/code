SWE-Gym

Real GitHub issue tasks with FAIL_TO_PASS and PASS_TO_PASS tests, built for training and verifying SWE agents. Lite (230) and Raw (64,689 unvalidated PR rows) variants exist.

How to use it

Use as a small, clean RL pool with per-repo Docker images from the SWE-Gym repo; pair with the SWE-bench test harness as verifier. Combine with larger sets for scale.

Caveats

Small. Only 2.4k tasks, so pass-rate filtering leaves little. Repo overlap with SWE-bench test repos is a known contamination concern for SWE-bench evals. Images must be built or pulled separately.
