ManyTypes4Py

Python dataset for machine-learning-based type inference, built from repositories that use type annotations.

How to use it

Train or evaluate type prediction for arguments, returns and variables. Use the clean version when you need labels that passed a type checker.

Caveats

Last commit 2022-03-27, so it predates recent typing features. Scoring is by match to the developer annotation, which can be wrong or needlessly narrow.
