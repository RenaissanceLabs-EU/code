MigrationBench

Repository-level migration from Java 8 to the long-term support versions 17 and 21. The GitHub repository provides the evaluation framework that judges a migration.

How to use it

Start with the 300-repository selected subset.

Caveats

The listed repositories are under MIT or Apache-2.0 per the README; the dataset rows hold repository names and commits, not the code. Evaluation needs Maven builds for every repository. GitHub last commit 2026-10-15.

load
from datasets import load_dataset
ds = load_dataset("AmazonScience/migration-bench-java-selected", split="test")
