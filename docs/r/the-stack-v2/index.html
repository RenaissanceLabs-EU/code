Dataset · 2024-02

The Stack v2

StarCoder2 training corpus built on the Software Heritage archive (2023), with per-file license labels. The HF release holds metadata and SWH blob ids; contents come from the SWH S3 bucket.

How to use it

Use the train-smol-ids or train-full-ids variants for the StarCoder2 mix, or the dedup variant for custom filtering. Must accept terms and fetch file contents separately from Software Heritage.

Caveats

Gated; accepting BigCode terms is required. Contents are not in the HF repo (need AWS access to SWH S3 and your own download tooling). License labels are heuristic (ScanCode), license laundering exists. Opt-outs only honored as of release date. Superseded by v3 for fresher data. Card could not be read without login, so sizes cite the v3 card.
