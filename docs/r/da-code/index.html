DA-Code

Agentic data science benchmark from EMNLP 2024: data wrangling and analytics tasks over real data, solved by writing and running code in a Docker sandbox.

How to use it

Run the provided agent harness in Docker and score with the task evaluation suite.

Caveats

The paper abstract reports 30.5% accuracy for the best model at release. This pass did not verify the task count. Languages is set to Python as the main language; the paper speaks of data science programming languages in general. Last commit 2026-01-12.
