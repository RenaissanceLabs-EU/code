CyberSecEval (Purple Llama)

Meta's suite for insecure-code generation and cyber misuse, with later versions adding more tests; also in inspect_evals (cyberseceval_2 to 4).

How to use it

Run as a safety gate for code models before release, alongside CWEval for dynamic checks.

Caveats

Original insecure-code tests use static analysis rules (CWEval's authors criticize unclear specs and impractical evaluation). Not execution-based for functionality. Repo license is mixed, so check it.
