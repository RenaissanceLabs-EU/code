CodeReviewQA

Benchmark that checks whether a model understands a code review comment, by breaking the job of revising code after review into three reasoning steps that are tested separately.

How to use it

Accept the access conditions on Hugging Face, then use it to find where a model fails between reading a review comment and producing the fix.
