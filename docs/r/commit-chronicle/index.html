Dataset · 2023-08

CommitChronicle

Commits with diffs, messages, author ids and dates, collected by JetBrains Research so that models can use a repository's history when writing a commit message.

How to use it

Use the default config for training on commit history. The subset_llm config (4,025 test rows) is a small evaluation set sized for LLM runs.

Caveats

Follow the per-row license and attribution terms. About 42 GB uncompressed per the card metadata. Last modified 2023-10-05.

load
from datasets import load_dataset
ds = load_dataset("JetBrains-Research/commit-chronicle", "subset_llm", split="test")
