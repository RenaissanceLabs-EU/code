AIOpsLab

Microsoft framework that deploys microservice applications, injects faults, generates workloads and exports telemetry, so that an agent can be evaluated on operations tasks such as fault detection and localization in a live system.

How to use it

Deploy it as the README describes, pick a problem from the built-in registry (for example a misconfiguration detection problem), and connect your agent through the orchestrator.

Caveats

Needs a deployed microservice environment and real compute per episode. Results depend on the agent's tools as much as on the model. Actively maintained (last commit 2026-10-20).
