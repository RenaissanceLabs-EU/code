Nemotron-Pretraining-Code-v3 (metadata)

Incremental metadata list of permissively licensed GitHub files for Nemotron 3 Ultra pretraining; use with v1/v2.

How to use it

Use to extend a v1/v2 corpus with 2025 data; you download files from GitHub yourself at the given commit.

Caveats

Metadata only, not code; GitHub rate limits and repo deletion cause attrition. Only incremental files, must be joined with v1 and v2. Not gated.
