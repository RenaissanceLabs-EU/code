Dataset · 2024-01

WebSight

Synthetic pairs of webpage screenshots and the HTML that produced them, generated by language models, for training screenshot-to-code models.

How to use it

Fine-tune a vision-language model on v0.2, then evaluate on Design2Code, which uses real pages.

Caveats

Fully synthetic and simpler than real sites. v0.2 is about 145 GB to download per the card metadata. Last modified 2024-03-26.

load
from datasets import load_dataset
ds = load_dataset("HuggingFaceM4/WebSight", "v0.2", split="train")
