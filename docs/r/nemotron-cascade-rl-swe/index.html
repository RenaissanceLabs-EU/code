Dataset · 2025-12

Nemotron-Cascade-RL-SWE

NVIDIA recipe data for SWE RL: difficulty-filtered mix of SWE-Bench-Train, SWE-rebench, SWE-smith, R2E-Gym-Subset and SWE-Fixer, with repos from SWE-bench Verified excluded to avoid contamination.

How to use it

Take as a template for mixing five sources and excluding eval repos. Reward there is execution-free (reward model), not Docker.

Caveats

Card states no Docker execution reward was used, so this is not an execution-verified recipe. Question counts are on the card; the SWE-Smith figure is garbled on the card.
