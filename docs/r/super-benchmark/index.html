Benchmark · 2024-09

SUPER

Allen Institute benchmark on setting up and running tasks from machine learning and NLP research repositories found on GitHub, including installing dependencies and fixing configuration problems.

How to use it

Report on the Expert set. Use Masked to locate which sub-skill fails, and Auto as development or training data.

Caveats

The paper abstract gives 602 automatically generated problems while HF shows 604. Research repositories rot, so some tasks may break over time. GitHub last commit 2025-04-04.

load
from datasets import load_dataset
ds = load_dataset("allenai/super", "Expert", split="all_examples")
