SWE-RL (Meta)

Scales RL for real-world software engineering with a lightweight rule-based reward (similarity to ground-truth patch) on open software evolution data.

How to use it

Cheap reward that avoids execution; consider as a pre-stage before execution-based RL.

Caveats

Similarity reward is a proxy and can reward style over correctness; repo code license NOASSERTION.
