RefactorBench

Multi-file refactoring tasks in popular open-source repositories, built to test whether an agent keeps track of its own earlier edits. From ICLR 2025.

How to use it

Run an agent in a Docker copy of each repository, as the README suggests, and check the result with the task's tests.

Caveats

The repository is archived; last commit 2025-07-11. The paper abstract reports agents solving 22% of tasks with base instructions at release.
