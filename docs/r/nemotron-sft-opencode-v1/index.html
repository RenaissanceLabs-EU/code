Nemotron-SFT-OpenCode-v1

Agentic instruction data for the OpenCode CLI: tool calling, AGENTS.md prompts, agent skills, bash-only tools and clarifying-question tool, in six subsets.

How to use it

Use to teach CLI-agent tool use and skills loading; match the harness format (OpenCode) at inference.

Caveats

Per card, questions and skills were synthesized with GPT OSS 120B and solution traces with Qwen3-Coder-480B-A35B-Instruct, so those terms apply. Tied to one harness format.
