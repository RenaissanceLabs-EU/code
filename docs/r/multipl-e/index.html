MultiPL-E

A system that transpiles unit-test-based Python benchmarks to many programming languages, with prebuilt translated sets.

How to use it

Use to check that a gain on Python carries over to other languages (Java, JS, Rust, Lua, etc.). Needs per-language toolchains, so run it in the provided containers; moderate cost.

Caveats

Execution-based. Inherits HumanEval and MBPP's saturation and contamination issues, and translated problems stay simple function-level tasks. Low-resource-language results are sensitive to translation artifacts. Per-config counts seen on the HF card: 157, 161, 161, 158 (first four configs).
