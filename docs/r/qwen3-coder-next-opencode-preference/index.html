Qwen3-Coder-Next OpenCode Preference

DPO pairs from rejection sampling: 8 samples per problem, chosen passes 100% of tests, rejected fails, with labeled rejection types. Companion to an SFT set of 49,374 examples.

How to use it

Test-verified on-policy-style pairs for competitive programming; hard-negative configs listed on the card.

Caveats

Third-party release by an individual; generated with Qwen3-Coder-Next (Qwen terms). Small.
