Dataset · 2018

Spider

Cross-domain text-to-SQL; databases are executable SQLite so execution accuracy gives a reward.

How to use it

Train GRPO with execution-match reward on SQLite, compare result sets.

Caveats

Saturated for strong models; the HF dataset has questions and gold SQL but SQLite databases come from the Spider site or a separate dataset.
