What is code?

A recipe, a law and a proof on paper are all exact writing, but each needs a person to carry it out or to judge it. Code is the one kind of writing that does not. It is reasoning set down so completely that a machine, which understands nothing, can execute it. That demand for total precision is a large part of the difficulty of programming, and all of its power.

Once written, a program acts alone. It can be copied without loss and run a billion steps a second, for decades, with nobody watching. Knowledge that used to live only in people (how to compute a payroll, route a call, land an aircraft) now exists outside any person and does the work itself. Code is the most general way we have found to put reasoning outside a human head and have it keep working.

Its nearest relative is mathematics. Mathematics says what is true, and code says what to do. The two meet exactly: a constructive proof can be read as a program, and a program can be proved. Our sister site maps mathematics. This one maps the half that moves.

The newest programs were not written at all. A trained model is a program whose behavior was found by a search over numbers, and such models now write code themselves. Code is the best ground for teaching them, for one reason: at many levels, a machine can check the answer.
